# Kindle Library Calculator

Library value, reading time and a Shelf of Shame for your Kindle books.

- Web version: https://bookshelf.kirbee213.tv
- Goodreads-synced version: install [Tampermonkey](https://www.tampermonkey.net/), then open `kindle-library-calculator.user.js` in this repo and click **Raw** to install it.

Books are saved in each visitor's own browser. Nothing is sent to a server.
